Neural Networks from Scratch in Pure Java

An eight-chapter, step-by-step guide to the mathematics and code behind learning.

About This Book

Build a neural network one understandable Java method at a time: vectors, matrices, neurons, layers, backpropagation, training, and evaluation. Every implementation uses Java 17 Standard Edition; you do not need a machine-learning or linear-algebra library.

Written for Java developers who know loops, arrays, classes, and methods but are new to AI or calculus. The chapters explain each idea with small numbers before turning it into readable, testable code.

  • Start small: compute a dot product and inspect every index in matrix multiplication.
  • Learn the mechanics: derive gradients and compare them with finite differences.
  • Make it work: train on logic gates, then classify handwritten digits from raw MNIST IDX files.
  • Run the examples: copy complete Java source listings and compile them with a Java 17+ JDK.
