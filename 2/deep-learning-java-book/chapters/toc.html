Preface

How to Read This Book

This book is written for Java developers who want to understand neural networks at a fundamental level. Every concept is built from the ground up using only the Java Standard Edition library. No external dependencies, no black boxes.

Code-first approach: Mathematical concepts are introduced alongside their Java implementations. You'll see the math, then immediately see how it translates to code.

Prerequisites: Comfortable with Java 17+ classes, arrays, loops, and methods. We introduce the algebra, derivatives, and matrix notation as they become useful.

Why Pure Java?

  • No magic: When you implement backpropagation yourself, you truly understand it
  • Tooling: Use the JDK compiler, debugger, and profiler to inspect your own numerical code
  • Portability: Runs on platforms with a compatible Java 17+ runtime
  • Clarity: Every array index and gradient can be inspected directly
  • Team adoption: Your Java team can read, maintain, and extend this code without learning Python
